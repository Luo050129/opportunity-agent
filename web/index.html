商机录入与分析助手 Agent

拜访记录 → CRM 十字段结构化 + 规则校验 + 结构化追问；判定全部来自题目给定规则

1. 输入拜访记录

支持粘贴文本与上传文件；不提供图片 OCR，截图请先转成文字。

一键样例：
规则依据（题目给定的 6 条分析规则 + S0–S5 阶段定义）
使用说明与输出字段说明

支持的输入：直接粘贴拜访记录文本；上传 .txt / .md / .csv / .docx / 文本型 .pdf。扫描件或加密 PDF 会明确提示无法解析，请改用粘贴文本。

规则怎么用：字段抽取、阶段判定与问题清单全部由 rules/ 下的题目规则与词典驱动（R-01 事实边界、R-02 推断处理、R-03 缺失信息、R-04 证据要求、R-05 矛盾处理、R-06 下一步行动，以及 S0–S5 达成条件），不依赖大模型常识自由判断。

输出字段：需求、核心场景、预算、决策人、影响人、时间计划、阶段、风险、下一步、未确认信息；每个字段带状态（事实／推断／未确认）与原话证据。

校验报告：是否合规、具体问题、对应规则、风险等级、整改建议、无法判断原因。

Agent 编排：本页底部的「执行轨迹」会展示本次的工具调用计划与逐步执行情况。有可用模型时由模型规划“调用哪些工具、按什么顺序”，没模型时用规则引擎默认编排；两者判定结果一致，因为字段值、证据与阶段全部由本地规则引擎的工具产出。

2. 分析结果

点击「开始分析」后，这里会展示 CRM 十字段、阶段判定过程、规则校验报告和待确认问题。

  • 字段结论带状态标签：事实 / 推断 / 未确认，并保留原话证据
  • 阶段判定可回溯到 S0–S5 达成条件，并说明“还缺什么证据”
  • 信息不足或规则未覆盖时，明确输出「无法判断，建议人工复核」
